# Calc_project

A simple calculator that handles basic arithmetic operations. This project was built to practice core logic, user interface design, and object-oriented programming concepts.

## Features
* **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
* **Dark Mode:** A sleek, eye-straining-free dark interface for comfortable use.
* **Responsive Layout:** The interface adapts perfectly to different screen sizes and dimensions.

## Technologies Used
* **Java** (Core Logic & UI framework)

## How to Run It

### Prerequisites
Make sure you have the **Java Development Kit (JDK)** installed on your computer (version 8 or higher recommended).

### Steps to Run
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory:**
   ```bash
   cd Calc_project
   ```
3. **Compile the Java file:**
   * *If your main file is named `Main.java`:*
     ```bash
     javac Main.java
     ```
4. **Run the application:**
   ```bash
   java Main
   ```
*(Note: Replace `Main.java` and `Main` with your actual primary filename if it is named something else, like `Calculator.java`.)*
